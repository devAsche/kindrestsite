# Kindrest — Quiet Hours theme

Custom Shopify Online Store 2.0 theme for kindreststore.com ("night sky + moonlight white").

- `theme/` — theme source (layout, sections, snippets, templates, assets, config, locales)
- Uploaded to Shopify as an **unpublished** theme via the Admin API (`themeCreate` from a staged ZIP).
  Never edit or publish the live (MAIN) theme from here.

## Playful touches (all toggleable in Theme settings → Playful touches)
- Screen-to-night intro (home, once per session, skipped for reduced-motion users)
- Star trail behind the cursor (desktop)
- "Quiet Hours" dim toggle with a shooting star
- Hero color swatches synced with the buy box
- Constellation-drawn 3-step ritual
- Star that flies into the cart on add-to-cart

## Copy rules
No "migraine"/"headache" in headings, no relief/medical claims, no unverified numbers.
